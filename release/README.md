# Profession-Archives v0.2.4-beta · 生涯大脑

> 本地优先的个人求职全流程管理工具 —— 从岗位采集、简历生成、投递看板、面试复盘到 offer 归档，一条龙自己在本地搞定，数据不出本机。

## v0.2.4 更新（AI 按官方文档对齐）

- **修正模型名**：DeepSeek 官方当前模型是 **`deepseek-flash`**（DeepSeek-V4.1-Flash）与 **`deepseek-v4-pro`**。
  上一版把 `deepseek-chat` / `deepseek-reasoner` 当作官方名 —— 那是旧代模型名，已下线，本版全部更正
  （默认值、设置页预设、报错提示）
- **按文档显式控制「思考模式」**：DeepSeek 思考模式默认开启且强度 high，对「结构化抽取」没有收益，
  只会显著变慢变贵，还会让 temperature 失效。现在 JSON 类任务（简历解析 / 字段识别 / 岗位提取）
  显式关闭思考模式；简历生成保留思考但降到 low
- **max_tokens 显式设置**（JSON 8192 / 文本 16384），并检测 `finish_reason=length`
  直接告诉你「输出被截断」，不再让你对着半截 JSON 猜
- **错误码按官方表给可操作提示**：401 Key 错 / 402 余额不足 / 429 限速 / 500·503 服务端
- 超时按文档「10 分钟未开始推理才断连」放大：JSON 120s / 文本 180s
- 设置页 Endpoint 提示填 base_url，模型名不在官方列表时红字提醒

> 对齐依据与结论表见 `docs/architecture.md` 4.3.1，改 AI 代码前先看那节。

## v0.2.3 更新（AI 排障 + 备份恢复重做）

**1. AI 简历解析排障**（此前表现为「点了没反应 / 提示未配置」）

- **修好配置同步**：以前 AI 配置只在「保存设置」时才同步给本地桥，重启后桥可能还在用旧配置 ——
  现在应用启动就会同步一次，设置页看到的就是桥实际在用的
- **错误现在真的会红着显示**：以前解析失败的报错被当成普通灰色提示显示，看着就像「点了没反应」
- 超时 15s → 90s（解析长简历本来就慢）；输出长度上限补上（以前长简历的 JSON 会被截断，报「不是合法 JSON」）
- **API 报错正文会透出来**：以前只显示「HTTP 400」，现在会带上 DeepSeek 返回的原因，
  模型名写错时还会提示官方模型名（当前为 deepseek-flash / deepseek-v4-pro）
- 设置页新增「**测试连接**」按钮 + 模型名预设（一键选官方模型），配错立刻能发现

**2. 数据备份 / 恢复重做**

- 导出可选**包含 AI 配置与 API Key**（默认不含，分享备份前更安全）
- 导入**先预览差异**（新增 / 覆盖 / 本地独有），再选 **完全替换**（回到备份那一刻）或 **合并**
- 导入前**自动留快照**，支持一次性「**撤销恢复到导入前**」
- 导入**永不删除**本机的 AI Key 与插件配对码（避免恢复旧备份把 Key 抹掉）
- 存储占用改为精确字节统计

**3. 默认数据清理**

- 冒烟测试不再把测试数据写进真实数据目录
- 本机遗留的示例档案（「林小安」）与测试库已清除

## v0.2.2 更新（投递看板大改版）

**1. 看板列完全自定义**（列取代原来的固定状态机）

- 列可**拖拽排序**、改名、设角色（进行中 / 成功 / 失败 / 归档），可增删
- 「＋ 加看板」：加回内置阶段（含第 4~8 面）或新建自定义列（如「待跟进」「已内推」）
- **删除看板时，列内投递有三种处置**：全部迁移到指定列 / 逐条指定去向 / 连同记录一起删除
- 迁移放开为自由移动（可回退、可从终态拉回修正）；推进 = 下一列；漏斗/统计按列顺序与角色自动计算

**2. 「列表」升级为 Notion 式多维表格**

- **自定义属性**：文本 / 长文本 / 数字 / 单选 / 多选 / 日期 / 勾选框 / 链接，可随时增删改
- **表格里直接编辑**：内置字段（公司、岗位、渠道、日期、重要性、标签…）和自定义属性都能就地改，不用开弹窗
- **看板列在表格里就是一个下拉** —— 改列即迁移，漏斗口径不受影响
- **筛选查询**：任意字段 + 运算符（按字段类型自动收敛）+ 且/或
- **排序**：点列头排序；**多套视图**可保存（各自记住筛选、排序、隐藏列、列顺序）
- **行选择 + 批量操作**：批量移动到某列、加/去标签、设重要性、删除
- **表内新增**：表格末尾一行直接敲岗位名回车即入库
- 内置字段**允许留空**（可先建条目再补信息），也可在「列管理」里隐藏 / 重新显示

> ⚠️ 看板列与自定义属性是**破坏性变更**（列取代了原固定状态机）。老数据会自动兼容：内置阶段沿用原 id，历史轮次列会自动补齐，不会丢投递。

## 怎么用

### 第一步：运行

- 下载解压后，**双击 `Profession-Archives-v0.2.4-win-x64.exe`**，绿色免安装，直接跑。
- 也可用安装包：`Profession-Archives_0.2.4_x64-setup.exe`（NSIS）或 `Profession-Archives_0.2.4_x64_en-US.msi`。
- 首次打开是空的 —— 没有预设数据，从零开始。
- 需要旧版请到 `历史版本/` 取（文件名带版本号）。

### 第二步：开始记录

推荐流程：

1. **生涯档案** → 填个人名片（姓名、技能、经历、项目），后续简历/填表靠这个
2. **岗位采集** → 看到感兴趣的公司/岗位，录入看板备选池（渠道、JD、标签）
3. **投递看板** → 看板视图拖卡片/改列推进；表格视图可自定义属性、筛选、批量操作
4. **面试复盘** → 每轮面试记录问题、回答、AI 即时反馈、录音归档
5. **简历生成** → 选投递 → 一键生成特化简历（JD 定向优化）、导出纯文本

### 第三步：装浏览器插件（可选，自动填投递表单）

插件可以：官网填表时一键自动填好姓名/邮箱/电话，人工确认后提交，同时自动回传看板"已投"。

#### 安装插件

1. Chrome / Edge 地址栏输入 `chrome://extensions`（Edge: `edge://extensions`）
2. 右上角打开「**开发者模式**」
3. 点「**加载已解压的扩展程序**」
4. 选择 `Profession-Archives-extension-0.1.1-chrome` 目录（**注意：是解压出来的文件夹，不是 zip 文件**）
5. 加载成功后浏览器工具栏会出现「Profession-Archives 助手」图标

#### 配对

1. 桌面应用打开左侧「**插件配对**」页，确认本地桥在线（绿灯）
2. 复制配对码
3. 浏览器点插件图标 → 粘贴配对码 → 保存配对
4. 之后在任何招聘网站详情页点「采集当前岗位」、在投递表单点「填充投递表单」

## 保存位置

所有数据存在本机：`%APPDATA%\com.professionarchives.app\`

- 桌面版业务数据：WebView localStorage
- 桥配对 token：`bridge-store.json`（含配对码与插件采集暂存 inbox）
- 桥同步的档案摘要 / AI 配置：`profile-summary.json`、`ai-config.json`
- 面试录制文件：`recordings/`

## 已知限制（测试版）

- **AI 能力分两路**：素材提炼 / 简历润色 / JD 匹配 / 面试复盘为**本地启发式**（无需联网、无需配置）；简历解析与特化简历生成会经本地桥调用**你配置的模型**（「设置 → AI 配置」填 DeepSeek 或 Ollama，未配置时会提示失败）
- **录屏需本机装 ffmpeg** 并加入 PATH 才能录系统声音；没装 ffmpeg 自动回退浏览器录屏（只有标签页声音）
- **插件自动填表**对少数动态表单（React/Vue 渲染、非标准控件）可能识别不准，需手动修补
- **仅 Win10+**（Win10 需 WebView2 运行时，Edge 已自带）
- **绿色版仅 x64**，暂无 32 位 / ARM 版本
