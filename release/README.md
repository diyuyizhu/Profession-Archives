# Profession-Archives v0.2.0 · Windows 公测版

本地优先的个人生涯大脑 + 求职面试全生命周期管理平台。**数据全在本机，默认单机运行**，无需联网。

## 使用

1. 双击 `Profession-Archives-v0.2.0-win-x64.exe` 直接运行（绿色版，免安装）。
2. 首次打开进入主控台（自带示例数据），可从「生涯档案」开始记录。
3. 所有数据保存在本机（应用数据目录），不会上传。

## 系统录屏

- 本机安装 [ffmpeg](https://ffmpeg.org/download.html) 并加入 PATH 后，面试录制自动启用**系统级录屏（屏幕 + 系统声音）**，视频保存到桌面端 recordings 目录并归档到投递档案。
- 未装 ffmpeg 时自动**回退网页录屏**（标签页声音 + 麦克风），任何用户都能录制。
- ⚠️ 公测版需自行安装 ffmpeg 才能录系统声音；内置 ffmpeg 将于 v0.2.1 提供。

## 功能（全部本地）

- 生涯档案：原子笔记（编辑/自定义池子）、聚合名片、时间线
- 投递看板：动态轮次（1–8 面）、筛选/排序/标签、看板/列表视图、投递详情档案
- 面试：多轮记录自动推进、AI 复盘、面经题库、邮箱导入、投递方式联动简历模板
- 系统录屏归档 + 一键复盘；自定义仪表盘（可拖动调大小/排序）

## 已知限制（公测版）

- 未打包 MSI/NSIS 安装包（WiX/NSIS 下载超时，后续补）；当前为绿色版 exe
- AI 助手当前为本地启发式（提炼/润色/匹配/复盘）；接入云端/本地大模型由后续服务端提供
- 浏览器插件（自动填充官网投递表单）需配合本地服务单独启动，见 `extension/README.md`

## 说明

- Windows 11（Win10 需安装 WebView2 运行时）
- 应用数据位于 `%APPDATA%\com.professionarchives.app\` 下
