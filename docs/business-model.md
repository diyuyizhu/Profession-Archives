# Profession-Archives 商业化模型（补充文档）

> 本文件为需求文档（[README.md](../README.md)）的**补充**，聚焦商业化策略。README 保持纯需求，商业决策单独沉淀于此，随讨论迭代。

## 一、核心准则

> **免费 = 开源抄得到的；付费 = 只有上云 / 上链才能做到的。**

- **本地优先 → 无云成本**：数据不上云，平台无服务器 / 存储 / 带宽成本，运营成本趋近于零。
- **开源生态已免费覆盖的能力一律免费**：简历生成、JD 匹配、投递看板、面试复盘等（GitHub 上大量可搜到的方案），免费提供以获客与建立信任。
- **只有云端 / 链上才能提供的能力，才是收费点**：AI 调用、名片托管、区块链存证。

## 二、分层模型

### 免费层（本地，零成本运营）

- 全部核心功能：原子档案、简历生成、投递看板、面试记录、复盘、JD 匹配。
- 本地 AI（Ollama 自备 Key/模型）：用户自带，无平台成本。
- 目的：获客 + 建立信任 + 培养"长期记录资产"的使用习惯。

### 付费层（云端 / 链上增值）

| 收费点 | 说明 | 定价参考 |
|---|---|---|
| **云端 AI 用量** | 平台内置分发（按 token / 包月额度）；BYOK 用户自带 Key 作为免费引流 | 包月额度或按次 |
| **名片托管** | A5 名片部署为稳定可访问 URL（附链上存证验证入口） | $2–5/月 |
| **区块链存证** | 经历 / 证书哈希上链，时间戳 + 完整性证明 | 打包进名片订阅或按次 |

## 三、区块链存证（定位修正与合规）

- **是"存证"而非"真伪认证"**：链上只证明"某内容在某个时间存在 + 之后未被篡改"，**不证明内容真实**。对外表述用"经历区块链存证 / 时间戳证明"，避免虚假宣传与信任反噬。
- **只上链哈希**：`SHA-256(经历内容)` 上链，明文永不上链，简历隐私不泄露。
- **合规**：不自建链，接入**已备案存证平台 API**（蚂蚁链 / 百度链 / BSN 存证接口），只做应用层，规避《区块链信息服务管理规定》备案主体问题。
- **验证闭环**：名片页 / 简历附带验证链接 → 验证方上传文件 → 本地算哈希 → 与链上比对 → 显示"完整、未篡改、存于 X 时刻"。

## 四、AI 双轨收费

- **BYOK（自带 Key）**：免费、零毛利，换口碑与生态。
- **平台内置分发**：按 token / 额度收费，真实收入。
- 参考成熟走法：免费日额度 + 平台 Key 按量（AnyJob 模式）。

## 五、定价带参考（2026 市场实测）

| 模式 | 代表 | 价格 |
|---|---|---|
| 免费 / 开源 | JobPilot、OrbitApply、AnyJob | $0 |
| 微付费 / 按次 | CVForge、ResumeSnipe | $0.06–0.59 / 次 |
| 买断制 | FilterGrade | $59 一次性 |
| 订阅制（云） | Teal $29/mo、Huntr $20/mo | $4.5–50/mo |

> 注意：高价订阅档全部是云 SaaS。本地优先工具的活路不在"高价订阅"，而在"本地工具做不到的增值"。

## 六、不建议的方向

- **平台高价订阅硬刚**：撞 Simplify（免费、1M+ 用户）、Teal/Huntr 免费层，且与本地优先矛盾。
- **自动化军备竞赛**（自动提交、破解验证码）：违背 README 的合规硬约束（人工确认），且市场已被这类产品卷烂。

## 七、执行顺序建议

1. 免费把模块 **D（自动化投递）+ A5（名片）** 做出来，积累用户。
2. **名片托管**作为第一付费点（最稳、成本最低、与 A5 差异化天然衔接）。
3. **AI 双轨**跟上（BYOK 引流 + 平台分发收入）。
4. **区块链存证**作为第二阶段差异化（先做证书/资质场景，可信度最高）。
5. 远期：**教育渠道 B 端授权**（对应"学生求职者"人群，高校就业中心 / 培训机构批量授权）。

## 八、与扩展方向的衔接

- 扩展方向第一梯队的**证书 / 资质管理**与链上存证天然联动——证书有编号与颁发机构，是存证可信度最高的场景。
- 行业包机制（计算机行业起步 → 多行业扩展）不影响商业化分层；内容按行业包扩展即可，收费点（AI / 名片 / 存证）跨行业复用。
